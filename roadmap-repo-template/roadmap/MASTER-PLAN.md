# MASTER PLAN (condensed)

**Honest target:** 12–18 months at 10–15 hrs/week to a credible entry-level portfolio. Professional depth takes years of real work.

## Phase 1 — Weeks 1–6: Computer, Networking & CLI
DNS, TCP/UDP, ports, HTTP/HTTPS/TLS, subnets; Windows + Linux terminal; Python basics (variables, loops, functions, file I/O).
Resources: Cisco NetAcad (free), Professor Messer Network+ (free), TryHackMe Pre-Security (free), OverTheWire Bandit (free).
Deliverable: network diagram + command cheat sheet + 3 tiny Python scripts.
Checkpoint: explain DNS, TCP vs UDP, HTTPS, and each script — without notes.

## Phase 2 — Weeks 7–12: OS + Security Fundamentals
Linux permissions/services/logs; Windows Event Viewer/PowerShell; CIA triad, least privilege, encryption vs hashing, threat modeling, risk, incident response.
Resources: Microsoft Learn (free), Linux Journey (free), OWASP Top 10 (free), NIST CSF (free).
Deliverable: log analyzer flagging suspicious logins; threat model of fictional workshop booking system.

## Phase 3 — Months 2–5 (parallel): Python + Vibe Coding
Functions, exceptions, JSON/CSV, argparse, logging, venv, pip, requests, APIs, unit tests, Git, HTML/CSS/JS basics, AI-assisted workflow (small diffs, tests, explanations).
Deliverable: deployed portfolio/workshop app; log-parser repo with tests.
Rule: review every AI diff; never paste secrets; test everything.

## Phase 4 — Months 4–6: First Certification
ISC2 CC (~$199 listed) OR CompTIA Security+ (~$425) — choose ONE under $500 budget.
Free study: Professor Messer Security+; paid ~$60 practice tests.
Book only when timed practice is consistently strong.

## Phase 5 — Months 5–9: Specialization Lane (pick ONE)
- SOC: events, Sysmon, SIEM, triage, MITRE ATT&CK → CySA+
- Web/AppSec: SQLi, XSS, auth, Burp → PortSwigger Academy → eJPT
- Cloud: IAM, logging, secrets, shared responsibility → AZ-900/SC-900 → role cert
- Automotive/IoT (niche): CAN/OBD-II, UDS, ISO/SAE 21434, UNECE R155 — simulators/bench rig only
Deliverable: 4–6 write-ups + one lane project with demo + threat model.

## Phase 6 — Months 8–10: Portfolio Projects
A) Workshop maintenance tracker (roles, CSV export) · B) Security log triage tool (tests) ·
C) Secure coding demo (vulnerable + fixed + threat model, never public) ·
Optional: CAN-log visualizer.
Every project: README, screenshots, setup, tests, limitations, threat model, demo video.

## Phase 7 — Months 11–12: Cert & Job-Readiness
CV translating technician strengths; LinkedIn + GitHub polished; 5–10 tailored applications + 2 networking conversations/week; mock interviews.

## Phase 8 — Months 13–18+: Experience + Staying Current
CTFs (CTFtime.org), home AD lab (Proxmox), open-source contributions, responsible disclosure within program rules; CISA/Krebs/THN weekly briefing; save for OSCP (~$1,749) after 6+ months labs.

## Final Rule
Learn fundamentals. Practise legally. Ship small tested projects. Use AI to accelerate — never replace — understanding. Document everything. Review weekly.
